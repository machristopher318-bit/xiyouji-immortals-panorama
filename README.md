作品阐释：《西游记妖怪身份审判庭》

本项目作为北京大学“西游记与中国文化”的期中创意作业。这是一个纯前端单页互动网站，以“天庭审判庭”为叙事框架，将《西游记》中的妖怪、神佛、取经团队与人间角色重新放入一个可审理、可辩论、可判决的虚拟法庭之中。访问方式：将 index.html 保存至本地并直接打开，或通过 GitHub Pages 发布地址在线浏览。

《西游记》表面上是一部降妖除魔的神魔小说，但若深入阅读便会发现，所谓“妖怪”并不总是单纯的邪恶符号。他们有的来自神佛体系的管理漏洞，有的承载地方势力、家庭矛盾与旧怨，有的则体现性别、欲望、身体与边缘身份的文化焦虑。本作品的核心意图在于：不再把取经路理解为简单的“打怪通关”，而是通过“审判”的形式，引导读者重新追问：谁有资格定义妖？谁掌握善恶解释权？一个妖怪的罪，究竟属于个体，还是也属于制造它的制度？

本网站以“天庭最高审判庭”为整体设定，用户进入页面后不再只是旁观者，而是成为天庭陪审员。页面通过案卷选择、证词阅读、角色图鉴、判决生成等模块，将《西游记》中原本分散在叙事中的人物关系与文化议题转化为一套可互动的审理流程。每一个案件都围绕一个经典情节展开，例如白骨精、红孩儿、金角银角、火焰山、盘丝洞等故事不再只是“妖怪被制服”的桥段，而被重新组织为包含被告、案由、证据、证词、文化解释与最终判词的完整案件。

纵向：从文本情节到文化审判

本作品首先将《西游记》的经典叙事拆解为一个个“案卷”。每个案件既保留原著中的基本情节，又进一步追问其背后的文化结构。例如，白骨精案讨论“识别”与“慈悲”的冲突；红孩儿案讨论儿童妖怪、家族权力与佛教收编；金角银角案则将问题指向神仙体系内部的法宝流失与管理责任。通过这种方式，网站把原本线性的取经故事转化为可供分析的审判文本，使读者能够在“案情”中看到更复杂的文化议题。

横向：多方证词中的立场冲突

网站并不提供单一答案，而是模拟法庭中的多方证词。孙悟空、唐僧、被告妖怪、神佛角色与现代读者都可能从不同角度解释同一案件。孙悟空强调效率与危险判断，唐僧强调慈悲与戒律，被告强调处境与怨气，神佛强调秩序与度化，而现代读者则进一步追问权力、性别、制度与叙事视角。这种横向并置使作品不再只是介绍人物，而是在不同声音的碰撞中展现《西游记》文本本身的开放性。

网状：妖怪身份背后的关系网络

本作品设置“角色图鉴 / 众生谱”模块，将取经团队、妖怪、神佛、人间角色等放入同一套人物系统之中。角色不再只是孤立的形象，而是处在亲缘、师徒、收编、降伏、旧识、职权和因果关系构成的网络中。例如，红孩儿背后有牛魔王与铁扇公主的家族关系；金角银角牵连太上老君的道教系统；黄风怪涉及佛门旧案与监管缺位。由此可见，《西游记》中的妖怪身份常常不是天然生成的，而是由关系、制度和叙事位置共同塑造的。

互动：由读者完成最后判决

本网站最重要的互动机制是“判决”。用户在阅读案情与证词之后，可以从“处死或镇压”“收编或度化”“情有可原”“制度问题，不只怪妖怪”“无罪，取经团队也有问题”等不同审判倾向中作出选择。系统会根据选择生成对应的判决书，并以“盖章”的形式完成审理。这个设计使读者意识到：判决并不只是对妖怪的评价，也暴露了审判者自身的文化立场。选择镇压，意味着强调秩序；选择度化，意味着相信收编；选择结构批判，则意味着把妖怪视为制度问题的显影。

审美实现：卡通古风中的游戏化法庭

视觉上，网站采用卡通古风与卷轴案卷结合的设计语言，以红、金、纸黄、墨色等色彩营造“天庭审判庭”的氛围。页面中设置了卷轴式主视觉、案卷卡片、角色头像、印章动画和法庭状态栏，使传统文本以更具游戏感和沉浸感的方式呈现。角色形象统一使用古风卡通风格，既保留《西游记》人物的辨识度，又适合网页交互、头像展示与案件卡片使用。

技术实现：纯前端单页互动网站

技术层面，本项目使用 HTML、CSS 与 JavaScript 构建，不依赖后端服务器。页面包含响应式布局、案件切换、随机抽案、证词标签切换、角色筛选、弹窗图鉴、判决生成与印章动画等功能。通过纯前端方式，作品实现了从“阅读文本”到“参与审判”的转变，使《西游记》的经典情节在网页交互中获得新的阐释空间。

总体而言，《西游记妖怪身份审判庭》并不是要替妖怪简单翻案，也不是要否定原著中的降妖叙事，而是希望通过审判庭这一创意形式，让读者看到《西游记》中更复杂的权力结构、道德判断与文化象征。每一个妖怪都可能不仅仅是妖怪；每一次降伏也可能不仅仅是正义战胜邪恶。本作品试图让古典小说从书页中走出，成为一场可阅读、可选择、可争辩、可反思的互动审判。
