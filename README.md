# 作品阐释：《西游记》神仙体系全景图
本项目作为北京大学“西游记与中国文化”的期中创意作业。
作者：马瑞霖
这是一个纯前端单页网站，使用平面分层结构、关系图谱和统计图表展示《西游记》中的神仙体系、阵营关系与文化象征。
访问方式：打开 GitHub Pages 发布地址即可直接浏览。

《西游记》不仅是一部神魔小说，更是一部微缩的古代社会结构百科全书。其神仙体系并非杂乱无章，而是存在严密的行政逻辑与派系博弈。本作品的核心意图在于，通过结构化的内容重组，将隐藏在叙事文本下的“天道秩序”转化为一套清晰的知识图谱，帮助受众理解吴承恩笔下“神、魔、人”不同神仙体系的复杂社会模型。
本作品通过NLP自然语言抓取，对《西游记》小说的庞大文本进行了多维度的知识解构，再将其呈现为可视化的网站：
纵向：神权统治的行政分层
网站梳理了仙界、人间、冥界（地府）的垂直空间秩序。通过对“分层神仙体系”的展示，揭示了小说如何模拟封建官僚体制，构建出一个从中央（天庭）到地方、从生界到死界的全覆盖行政网。
横向：多元意识形态的派系共生
内容涵盖了天庭官僚、道教教派（如三清）、佛教集团、地府冥界以及游离于体制外的妖族阵营。这种横向划分重点探讨了不同势力间的职权交叉与权力边界，例如道教高层与天庭行政长官之间的身份重叠。
网状：人物关系的社会属性
利用关系图谱呈现人物间的社会连接，包括师徒传承、敌对降伏、同门渊源等复杂纽带。这一模块旨在说明，西游世界中的冲突往往不是简单的善恶对立，而是基于派系背景、职场利益或裙带关系的精密互动。
量化：文本角色的分布特征
通过对各阵营人物数据的量化汇总，呈现了原著中角色比例的分配趋势。有助于观察作者在构建世界观时对不同文化势力（如道法与佛法）的侧重程度。
技术实现：采用 Tailwind CSS 框架构建出平滑的响应式视窗布局，适配一般用户的阅读体验。引入开源可视化库 ECharts 构建图谱核心，配合重绘、多向筛选与平移缩放算法，让古老的西游文本在代码跃动中实现“活化”。现已将该项目开源至GitHub平台。
